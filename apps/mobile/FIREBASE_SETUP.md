# Firebase Setup

## Required Files

1. **Android**: Place `google-services.json` in `apps/mobile/android/app/`
   - Get from Firebase Console → Project Settings → General → Your apps → Android

2. **iOS**: Place `GoogleService-Info.plist` in `apps/mobile/ios/`
   - Get from Firebase Console → Project Settings → General → Your apps → iOS

## Development Emulators

Use `firebase emulators:start` for local development with emulators.
